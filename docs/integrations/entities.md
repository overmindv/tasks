# Интеграция с entities

`entities` остаётся владельцем канонических тем. В MVP связь необязательна: `tasks-it.task_versions.topic_id` хранит только UUID без database foreign key и без копирования темы.

Список тем для административной формы запрашивается по цепочке `frontend -> api-gateway -> entities`. Если подходящей темы нет, `topic_id` не передаётся.

В будущем `tasks-it` может проверять выбранный UUID через внутренний API `entities` перед записью новой версии. Такая проверка должна иметь timeout и явную ошибку внешней зависимости; исторические версии не изменяются при переименовании или удалении темы.
