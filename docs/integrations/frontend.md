# Интеграция с frontend

`frontend` должен работать только с GraphQL `api-gateway` и не знать внутренний URL `tasks-it`.

Административная форма получает возможные темы через query каталога `entities`, позволяет оставить тему пустой и отправляет полный набор вариантов. Для multiple choice UI разрешает несколько правильных вариантов, для single choice — один.

Экран решения сохраняет `taskVersionId` и option IDs из загруженного теста. При submit создаётся новый UUID `idempotencyKey`, который повторно используется только для retry того же действия.

Если результат содержит `taskUpdated=true`, показать плашку: «Тест был обновлён. Ответ проверен по версии, которую вы открыли» и действие для загрузки `latestTaskVersionId`. История отображает verdict, номер версии и время решения.

Для будущего экрана programming-задачи слева отображаются statement, examples и constraints, справа до появления редактора — выбор языка и одного файла. Разрешены только `.py` для Python и `.go` для Go. После submit UI сохраняет `codeSubmission.id`, показывает `queued` и опрашивает результат через GraphQL gateway с ограниченной частотой до `completed`; прямого доступа frontend к Kafka или `tasks-it` нет.
