# OVM-245 — изоляция попыток

Дата: 2026-11-15. Jira: https://overmindv.atlassian.net/browse/OVM-245.
Ветка codex/ovm-245-attempt-fencing основана на be57381 (OVM-241).

## Результат

Retry атомарно заменяет execution_id (wire attempt_id), увеличивает attempts
и записывает outbox. CAS сверяет предыдущий ID; row lock сериализует reaper/result.
Completion остаётся защищён execution_id/task_version/status CAS.
Поздние и повторные ответы по другим Kafka coordinates сохраняются как stale inbox.
Повтор тех же coordinates идемпотентен. Payload в inbox не сохраняется.

Оба обработчика используют persisted next_attempt_at текущей попытки и MaxAttempts;
после истечения срока применяют общий retry-or-exhausted переход. Submit теперь
сохраняет attempts=1 и полное окно now+RetryGrace (раньше INSERT пропускал эти поля).
Повторный stale reaper-кандидат не расходует новую попытку. Исчерпание лимита
даёт infrastructure_error, а не неверный ответ студента.

Ошибки чтения БД сохраняют retryable-классификацию; permanent mismatch остаётся
только для подтверждённо отсутствующего submission/version и неверных идентификаторов.

## Миграция и rollout

202611150001_execution_attempt_fencing.sql расширяет inbox status check.
Применить до бинарника. Старые workers/reaper остановить перед новой версией:
смешанный rollout не защищён, старый бинарник не соблюдает fencing.
Down сохраняет записи, переводя stale в rejected с STALE_ATTEMPT.
Прежние миграции не изменялись. HTTP/GraphQL/Kafka schema не менялись.

## Ограничения

Deadline общий для текущей попытки, не новый глобальный SLA. RetryGrace должен
покрывать очередь и внутренний retry-budget sandbox. Старое sandbox execution
удалённо не отменяется; его результат безопасно отбрасывается как stale.
История attempt ID отдельной таблицей не добавлялась. Sandbox не изменён.
Полный gateway/frontend/gojudge e2e и deployment не запускались.
Для build используется CGO_ENABLED=0 из-за известного локального macOS SDK/linker
конфликта, lint — Go 1.26.1 вместо несовместимого с линтером системного Go 1.27.1.
CodeGraph отсутствует в среде; навигация выполнена rg/компилятором/исходниками.

Docs сохраняет чужие незавершённые status/startup-catalog изменения. Общий markdown
lint имеет прежние MD022 в startup-catalog; новые спецификации проверяются отдельно.
Push/merge/deployment не выполняются. Следующая задача — OVM-246, полнота результатов.
