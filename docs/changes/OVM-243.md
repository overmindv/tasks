# OVM-243 — публикация приватных наборов

Администратор создаёт draft для текущей programming-версии, редактирует с CAS
revision и публикует. Публикация требует хотя бы один hidden case. Манифест
`sandbox.inputs.v1` содержит только входы, без эталонных ответов и checker.
S3 conditional PUT запрещает замену объекта; повтор с теми же байтами безопасен.
После загрузки транзакция проверяет revision и базовую версию, создаёт новую
TaskVersion и привязку suite. Ошибка загрузки не меняет текущую версию.
Orphan после конкурентного изменения удаляется отдельным процессом уборки.

Настройки writer: `TASKS_SUITE_S3_ENDPOINT`, `TASKS_SUITE_S3_REGION`,
`TASKS_SUITE_S3_BUCKET`, `TASKS_SUITE_S3_ACCESS_KEY_ID`,
`TASKS_SUITE_S3_SECRET_ACCESS_KEY`, необязательный `TASKS_SUITE_S3_PREFIX`.
Bucket приватный; reader sandbox получает отдельные read-only credentials.
Ключ: `<prefix>/<suite_id>/<revision>/suite.json`. Без настроек draft API работает,
публикация возвращает `SUITE_STORAGE_UNAVAILABLE`. Используется AWS SDK v2.

Проверено: race unit, ACL всех маршрутов, conditional PUT на HTTP сервере,
публикация и CAS на выделенной PostgreSQL 17, build, vet, lint.
