## Реализовано

- Sandbox schemas отражают существующий stdin/execution mode, ok/cases/summary.
- Tasks содержит точные snapshots двух schemas; старые проекты помечены историческими.
- Шесть общих request/result fixtures для execution, pytest, go-test проверяются
  JSON Schema и реальными Go decoder/validator/encoder. Есть negative cases.
- CI обеих сторон валидирует схемы; локальный --peer обнаруживает дрейф snapshots.
- Producer tasks использует submission_id как Kafka key (submit и requeue),
  передаёт неизменяемый task_version_id через существующее metadata.
- Владельцы retry, переход на v2 и открытый runtime gap OVM-245 документированы.
- Изменения sandbox явно разрешены пользователем для этой задачи.
