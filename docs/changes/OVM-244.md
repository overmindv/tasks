# OVM-244 — пробные и оцениваемые решения

`run_mode=samples|graded` хранится в code_submissions и включён в fingerprint.
Отсутствующее поле и legacy-строки означают samples; старый fingerprint принимается
только для повторного samples-запроса. Повтор ключа с другим режимом — конфликт.
Samples исполняет открытые examples и не влияет на прогресс/рейтинг, включая
исторические запуски. Graded требует suite для указанного TaskVersion и его язык.

TaskVersion — неизменяемая привязка к suite. Retry загружает набор по сохранённой
версии submission, независимо от current_version задачи. Outbox graded содержит
`execution.suite` (ID/version/checksum) вместо входов; metadata содержит run_mode.
Sandbox проверяет приватный manifest `sandbox.inputs.v1`, разрешает только stdin,
возвращает контекст фактических входов. Tasks проверяет полноту и сравнивает вывод
через exact/trim_newlines. Hidden stdout/stderr очищаются до записи в БД.
Public DTO не содержит suite reference и скрытых кейсов.

Публикация suite ограничена runtime policy tasks (CODE_EXECUTION_PYTHON_VERSION /
CODE_EXECUTION_GO_VERSION). Она должна совпадать с sandbox registry. Опубликованные
runtime нельзя удалять из registry, пока существуют решения для retry.
Workspace ограничен hard max sandbox: 10 MiB.

Развёртывание: сначала совместимый sandbox reader, затем миграции и tasks.
Не смешивать старые tasks workers с новыми graded-запросами. Настройки приватного
writer описаны в OVM-243; reader использует SANDBOX_TESTS_* и feature flag object
storage tests. Bucket/prefix должны совпадать, reader credentials — read-only.
Ключ stdin manifest: `<prefix>/<suite_id>/<revision>/suite.json`.
API/UI переключатель gateway/frontend остаётся отдельной OVM-102; старый gateway
продолжает отправлять samples. Для graded нужен новый REST caller.

Проверки: race unit обоих сервисов, PostgreSQL 17 migrations/component, отдельно
progress/rating component, общий contract script (7 fixtures и negative cases),
tasks lint, vet/build обоих сервисов. Независимое review: исправлены границы
workspace и runtime policy. Полный стек с реальным gojudge/S3 не запускался.
