# OVM-246 — полнота результатов

## Реализовано

Tasks сверяет opt-in evaluation_context версии и SHA-256 упорядоченных входов
с сохранённой TaskVersion. Sandbox вычисляет checksum сам, не копирует его
из metadata. Проверяются полнота, уникальность, границы индексов и summary.
Run-level failure не скрывается успешными cases; infrastructure_error имеет
приоритет над ошибкой пользователя, checker_error отделён от wrong_answer.
Signal, exit code и усечение вывода исключают accepted. Чужие user/trace/language
при наличии этих полей отклоняются; attempt fencing OVM-245 сохранён.

## Совместимость и ограничения

Сначала sandbox, затем tasks; остановить старые consumers tasks. Расширение
только по metadata.result_context_version="1"; старые запросы не получают новых
полей. Старые queued результаты без контекста запускают bounded retry; при
исчерпании лимита infrastructure_error. БД/HTTP/GraphQL без изменений.
Checksum — проверка корреляции доверенного runner, не аттестация исполнения.
Suite пока содержит открытые примеры; OVM-244 остаётся открытой. Полный live
Kafka/gojudge/gateway e2e не запускался. Build CGO=0 из-за локального SDK,
lint Go1.26.1 из-за несовместимости линтера с системным Go1.27.
